# 📊 Agregador de Dados para Declaração de Imposto de Renda (Excel)

## 📌 Descrição do Projeto
Este projeto consiste na criação de uma ferramenta em **Microsoft Excel** para auxiliar na **organização e centralização de informações essenciais para a Declaração de Imposto de Renda Pessoa Física (IRPF)**.

A solução foi desenvolvida inteiramente no Excel, utilizando recursos nativos da ferramenta para garantir **facilidade de uso, validação de dados e organização estruturada das informações**, permitindo que o usuário registre e consulte seus dados de forma prática e segura.

---

## 🎯 Objetivo
Facilitar o controle e o agrupamento de dados necessários para a declaração do imposto de renda, reduzindo erros, retrabalho e perda de informações ao longo do ano-base.

---

## 🧠 Funcionalidades Implementadas
- Organização dos dados por **abas temáticas**
- Estrutura preparada para **entrada validada de informações**
- Separação clara entre dados do titular, informes e anotações
- Interface simples e intuitiva
- Planilha pronta para uso contínuo ao longo do ano

---

## 🗂️ Estrutura da Planilha

### 📄 Aba **TITULAR**
- Cadastro das informações principais do contribuinte
- Dados pessoais utilizados na declaração do IR

### 📄 Aba **INFORMES**
- Registro de informes de rendimentos
- Centralização de dados fornecidos por fontes pagadoras

### 📄 Aba **NOTAS**
- Espaço destinado a observações gerais
- Anotações importantes relacionadas à declaração

### 📄 Aba **TABELAS**
- Tabelas de apoio para organização e padronização dos dados
- Base para validações e futuras automações

## 🚀 Como Utilizar
1. Faça o download do arquivo `ORGANIZADOR DE IR.xlsx`
2. Preencha os dados conforme cada aba
3. Utilize o arquivo ao longo do ano para manter as informações organizadas
4. Use os dados como apoio no momento da declaração do Imposto de Renda
